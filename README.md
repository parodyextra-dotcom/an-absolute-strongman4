# 절대강자 분할환전

다중 통화 환전 포트폴리오 관리 모바일 웹 앱입니다.

## 주요 기능

### ✅ 구현된 기능

1. **다중 통화 지원**: USD, JPY, EUR, CNY 4개 통화 포트폴리오 관리
2. **실시간 환율 조회**: exchangerate-api.com API를 통한 실시간 환율 데이터
3. **분할 매수/매도**: 회차별 매수·매도 관리
4. **투자 등급 시스템**: 수익률 기반 등급 (비기너 ~ 플래티넘)
5. **환율 계산기**: KRW ↔ 외화 계산
6. **통계 페이지**: 투자 현황 차트 및 분석
7. **데이터 백업/복원**: JSON 기반 데이터 내보내기/가져오기
8. **목표 매수환율 설정**: 통화별 목표 매수환율 입력
9. **🔔 목표환율 도달 알림 시스템 (NEW)**:
   - **30초 간격** 실시간 환율 체크
   - **알림 소리** (Web Audio API) - 목표 도달 시 반복 경보음
   - **브라우저 푸시 알림** - 웹을 닫아도 알림 수신
   - **Service Worker** 백그라운드 환율 모니터링
   - **알림 배너 UI** - 페이지 상단에 긴급 알림 표시
   - 통화별 개별 알림 해제/재활성화
   - 소리 ON/OFF 토글

## 파일 구조

```
index.html    - 메인 앱 (SPA)
sw.js         - Service Worker (백그라운드 환율 체크 + 푸시 알림)
README.md     - 프로젝트 문서
```

## 기능 진입 URI

| 경로 | 설명 |
|------|------|
| `/` 또는 `/index.html` | 메인 앱 (홈 페이지) |
| 하단 네비게이션 `홈` | 전체 포트폴리오 요약 |
| 하단 네비게이션 `환율` | 실시간 환율 조회 |
| 하단 네비게이션 `투자` | 분할 매수/매도 관리 + 목표환율 설정 |
| 하단 네비게이션 `계산기` | 환율 계산기 |
| 하단 네비게이션 `통계` | 투자 통계 차트 |

## 알림 시스템 동작 방식

### 웹이 열려있을 때
1. **30초마다** 환율 API를 호출하여 최신 환율을 가져옵니다
2. 목표 매수환율 이하로 떨어지면:
   - 🔊 알림음이 3초 간격으로 반복 재생됩니다
   - 📢 페이지 상단에 알림 배너가 표시됩니다
   - 🔔 브라우저 알림도 함께 발송됩니다

### 웹을 닫았을 때 (Service Worker)
1. Service Worker가 **30초마다** 백그라운드에서 환율을 체크합니다
2. 목표 환율에 도달하면:
   - 📱 **브라우저 푸시 알림**이 발송됩니다 (진동 포함)
   - 알림 클릭 시 앱이 열립니다
3. **주의**: 알림 권한(`Notification.requestPermission()`)을 허용해야 동작합니다

### 알림 끄기
- 알림 배너의 "알림 끄기" 버튼으로 전체 해제
- 개별 통화별 해제 가능
- 목표 매수환율 설정 영역에서 "이 통화 알림 다시 켜기"로 재활성화

## 기술 스택

- **HTML5 / CSS3 / JavaScript** (순수 SPA)
- **Tailwind CSS** (CDN)
- **Chart.js** (차트)
- **Lucide Icons** (아이콘)
- **Web Audio API** (알림 사운드)
- **Service Worker** (백그라운드 알림)
- **Notifications API** (브라우저 푸시 알림)
- **LocalStorage** (데이터 저장)
